# Measure-of-Music-2025-Project-Gigatlas-Prototype
Explore my work on GigAtlas, an AI-assisted tour planning prototype. This repository includes the Python code, synthetic datasets, and scoring methodologies I developed to identify top touring cities and suitable venues for independent artists.

## Repository Contents

- **`Create Index.ipynb`**: The notebook where I built the top-cities index and the candidate venues for each artist.
- **`data/`**: Toy (synthetic) data generated by Claude, used as a stand-in for paid music-industry APIs.
- **`output/`**: Results produced by running the index framework on the toy data.
- **`app/`** and **`Claude Code Work/`**: The interactive prototype I built with Claude Code. `app/` holds the front end, and `Claude Code Work/` holds the supporting methodology, logistics-planning notebook and data-generation scripts.
